# 📚 Entregables Semanales – Proyecto Web NeoCraft Ropa.

## 👋 Bienvenidos

Este repositorio ha sido creado con el propósito de **organizar, documentar y realizar el seguimiento de las entregas semanales** correspondientes al desarrollo de mi proyecto web.

A lo largo del proyecto se irán agregando los diferentes avances, actividades, evidencias y entregables realizados durante cada semana, permitiendo llevar un registro ordenado del proceso de aprendizaje y desarrollo.

## 🎯 Objetivo del repositorio

El objetivo principal es mantener organizadas las actividades realizadas semanalmente y mostrar de manera clara la **evolución del proyecto web**, desde sus primeras etapas hasta su desarrollo y finalización.

Este repositorio permite:

- 📌 Organizar las entregas realizadas cada semana.
- 💻 Registrar los avances del proyecto web.
- 📂 Mantener las evidencias y archivos del proyecto.
- 📈 Hacer seguimiento al proceso de desarrollo.
- 🧠 Aplicar los conocimientos adquiridos durante la formación.
- 🔄 Identificar los cambios y mejoras realizadas al proyecto.

## 📅 Entregables semanales

Cada semana contará con su respectiva Sección o Documento, donde se incluirán los trabajos y avances correspondientes.

### Semana 1
📌 **Actividad:** Analisis y Requisitos.

### Semana 2
📌 **Actividad:** Diseño del sistema.

### Semana 3
📌 **Actividad:** Desarrollo del Frontend.

### Semana 4
📌 **Actividad:** Base de datos y Backend.

### Semana 5
📌 **Actividad:** Funcionalidades Principales.

### Semana 6
📌 **Actividad:** Integración del Sistema.

### Semana 7
📌 **Actividad:** Pruebas, Calidad y Correcciones.

### Semana 8
📌 **Actividad:** Entrega Final y Sustentación.

> Las semanas y actividades se irán actualizando a medida que avance el proyecto.

## 🖥️ Sobre el proyecto web NeoCraft Ropa.

El proyecto web se desarrolla de manera progresiva, aplicando los conocimientos adquiridos durante el proceso de formación.

Cada nueva entrega representa un avance en la construcción del proyecto, permitiendo observar cómo se incorporan nuevas funcionalidades, mejoras de diseño, organización del código y diferentes herramientas de desarrollo web.

## 🚀 Proceso de trabajo

El proyecto seguirá un proceso de desarrollo progresivo:

**Planificación → Desarrollo → Pruebas → Correcciones → Mejoras → Entrega**

De esta manera, cada semana se busca avanzar un poco más en la construcción del proyecto y fortalecer los conocimientos adquiridos.
